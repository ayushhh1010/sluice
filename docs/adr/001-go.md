# ADR-001: Go

**Status:** accepted

**Context.** About six weeks of part-time work. The hard parts are ordering, fencing and failure handling, not raw CPU speed.

**Decision.** Go (1.27).

**Why.** franz-go's `kmsg` removes the hand-written Kafka codec for every API and version. Goroutines and the standard `net` package fit
a connection-heavy, I/O-bound server. WarpStream and Bufstream, the closest production systems, are written in Go. Memory safety removes
a class of debugging time.

**Costs accepted.** Garbage-collection pauses, which become a test case: a paused sequencer is exactly the zombie the simulator injects.
Go's scheduler is not deterministic, which forces the sans-I/O core design (ADR-006).

**Rejected.** C++ (viable, as Redpanda shows, but async networking, the AWS SDK, a codec and memory bugs roughly double the build);
Rust (strong signal, but the learning curve does not fit the timeline); Python or Node (CRC32C and batch parsing would bottleneck).
